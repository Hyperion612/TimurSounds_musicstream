# Настройка pCloud для TimurSounds

## Что такое pCloud?

pCloud — это облачное хранилище с прямым стримингом аудио. В отличие от MEGA, pCloud:
- ✅ Нет лимитов на скачивание
- ✅ Быстрая доставка через CDN
- ✅ Прямые ссылки на файлы для стриминга
- ✅ Бесплатно 10 ГБ
- ✅ Стабильная работа из браузера

## Как подключить pCloud

### Шаг 1: Регистрация

1. Перейдите на [pcloud.com](https://pcloud.com)
2. Зарегистрируйте аккаунт (бесплатно, 10 ГБ)
3. Подтвердите email

### Шаг 2: Получение Access Token

pCloud использует OAuth 2.0 для авторизации. Есть два способа получить токен:

#### Способ 1: Через настройки аккаунта (проще)

1. Войдите в [my.pcloud.com](https://my.pcloud.com)
2. Откройте настройки: [my.pcloud.com/app#settings](https://my.pcloud.com/app#settings)
3. Найдите раздел "API" или "Developers"
4. Создайте новое приложение или скопируйте существующий access token

#### Способ 2: Через OAuth API (для продвинутых пользователей)

1. Зарегистрируйте приложение на [docs.pcloud.com](https://docs.pcloud.com/)
2. Получите `client_id`
3. Используйте OAuth flow для получения токена

### Шаг 3: Подключение в админке

1. Откройте админку TimurSounds
2. Перейдите на вкладку "Синхронизация"
3. В разделе "Хранилище аудио" найдите блок "pCloud"
4. Вставьте access token в поле
5. Нажмите "Проверить и подключить PCLOUD"
6. Дождитесь сообщения "pCloud подключён"

### Шаг 4: Загрузка треков

После подключения:
1. Перейдите на вкладку "Треки"
2. Нажмите "Добавить трек"
3. Выберите аудиофайл
4. Заполните информацию (название, артист и т.д.)
5. Нажмите "Опубликовать"

Файл автоматически загрузится в pCloud в папку `/TimurSounds/audio/` и будет доступен всем слушателям.

## Структура файлов в pCloud

```
/TimurSounds/
  └── audio/
      ├── track_abc123.mp3
      ├── track_def456.mp3
      └── ...
```

Каждый трек получает уникальное имя (trackId) и публичную ссылку для стриминга.

## Преимущества pCloud перед MEGA

| Функция | pCloud | MEGA |
|---------|--------|------|
| Лимит скачивания | Без лимитов | Ограничения на трафик |
| Скорость доставки | CDN, быстро | Медленнее |
| Прямой стриминг | ✅ Да | ❌ Нет |
| Бесплатное место | 10 ГБ | 20 ГБ |
| Шифрование | На сервере | На клиенте |
| Стабильность API | Высокая | Средняя |

## Устранение неполадок

### Ошибка "Неверный токен доступа"

- Убедитесь, что токен скопирован полностью
- Проверьте, что токен не истёк
- Попробуйте создать новый токен

### Ошибка "Не удалось загрузить файл"

- Проверьте размер файла (максимум зависит от вашего тарифа)
- Убедитесь, что в аккаунте есть свободное место
- Проверьте консоль браузера (F12) на ошибки

### Треки не играют на других устройствах

- Убедитесь, что pCloud подключён (индикатор "PCLOUD АКТИВЕН")
- Проверьте, что треки загружены (в админке должно быть "аудио в pCloud")
- Очистите кэш браузера на другом устройстве

## Безопасность

- Access token хранится только в вашем браузере (localStorage)
- Рекомендуется использовать отдельный аккаунт pCloud для площадки
- Не передавайте токен третьим лицам
- При компрометации токена — создайте новый в настройках pCloud

## Альтернативные хранилища

Если pCloud не подходит, площадка поддерживает:
- **MEGA** — зашифрованное облако, 20 ГБ бесплатно
- **GitHub Releases** — файлы до 2 ГБ, CDN GitHub
- **Cloudflare R2** — быстрый CDN, нулевой egress
- **Supabase Storage** — если уже используете Supabase
- **Локальное хранилище** — только для вашего устройства

Приоритет: pCloud → MEGA → R2 → GitHub → Supabase → локально.

## Поддержка

Если возникли проблемы:
1. Проверьте консоль браузера (F12 → Console)
2. Убедитесь, что access token действителен
3. Проверьте, что в аккаунте есть свободное место
4. Попробуйте переподключить pCloud

Документация pCloud API: [docs.pcloud.com](https://docs.pcloud.com)
